# 双相机外参快速采集页设计

## 目标

在现有 ThirdHand Web 服务中增加一个独立的双相机外参验证页面，让操作员在机械臂保持静止时快速完成 10 个不同 ChArUco 姿态的采集，并即时看到每次采集的质量门禁与总进度。

## 边界

- 页面和 API 只读取 Lumos、D435 图像并写入标定验证证据。
- 页面不导入、不调用机械臂、CAN、夹爪或主动视角控制模块。
- 旧外参始终是 `candidate_only`；即使 10 个姿态通过，本页面也不把它变成可执行抓取标定。
- 输出目录、候选外参、标定板配置和相机 URL 均由服务端配置，浏览器不能提交路径或命令。
- 不提供删除、覆盖或重置证据的网页接口。

## 方案选择

采用独立页面 `calibration-capture.html`，复用现有 Node Web 服务，并通过单独的 `calibration-capture-api.js` 调用现有 Python 验证脚本。

未采用的方案：

- 把采集控件放进 `camera-test.html`：会混合目标识别、主动视角和标定职责，页面也更拥挤。
- 新建独立 Python Web 服务：会复制静态文件、端口和生命周期管理，增加部署复杂度。

## 模块

### 浏览器页面

`web-control/web/calibration-capture.html` 只定义采集布局；`calibration-capture.js` 只处理状态轮询、采集请求和渲染。

页面包含：

- Lumos 与 D435 两个实时画面。
- 固定标定板说明：12 列、9 行、15 mm 方格、11.25 mm 标记、`DICT_5X5_100`。
- 10 格姿态进度与通过/拒绝状态。
- 最新一次公共角点数、D435 重投影 RMSE、Lumos P95、采集时差和姿态编号。
- 明确的“机械臂保持静止”“不会控制机械臂”安全提示。
- 一个“采集当前姿态”按钮；请求进行中禁止重复点击。
- 采集成功后提示移动或倾斜标定板，再采下一姿态；错误直接显示可操作原因。

### Node API 适配器

`web-control/server/calibration-capture-api.js` 是唯一的 Web 到 Python 适配层：

- `GET /api/calibration/status` 返回经过白名单裁剪的清单摘要与观察结果。
- `POST /api/calibration/capture` 不接收业务参数，自动生成下一个 `pose-NN`。
- 同一时刻最多运行一个采集进程。
- 只接受本机连接，响应禁用缓存，并限制 Python 输出大小和执行时间。
- 通过依赖注入提供 runner，便于在不连接相机时测试协议。

`proxy.js` 只负责挂载路由，不包含标定算法。

### Python 采集接口

复用 `scripts/vision/validate_legacy_dual_camera.py` 的标定板检测、相机模型投影、质量门禁与原子证据写入。增加稳定的 JSON 输出模式和“要求新姿态”选项：

- 新姿态相对已保存姿态至少平移 15 mm 或旋转 3°。
- 重复姿态在写入前拒绝，不污染验证集。
- 有效样本要求公共角点不少于 24、D435 RMSE 不高于 1.5 px、Lumos P95 不高于 4 px。
- 单次像素门禁失败也拒绝写入，保证页面中的进度只表示合格样本。

## 数据流

1. 浏览器显示现有同源相机流并轮询状态 API。
2. 操作员放置标定板并点击采集。
3. Node 适配器自动选择样本 ID，启动一次受限 Python 进程。
4. Python 并发抓取原始 Lumos 与 D435 帧，检测同一标定板并计算误差。
5. 任一门禁失败时不写证据，错误返回页面。
6. 通过时原子写入图像与内容寻址清单；Node 读取并裁剪结果；页面更新进度。
7. 第 10 个不同姿态通过后，页面显示旧双相机外参是否验证通过，并继续提示手眼与桌面标定仍未完成。

## 错误处理

- 任一相机不可用、图像尺寸不符、标定板角点不足、公共角点不足、像素误差超限或姿态重复，均拒绝本次采集并保留已有证据。
- Python 超时、异常退出、输出不是预期 JSON 或清单完整性失败，API 返回稳定错误代码，不回显命令行或本机路径。
- 前端网络中断后可通过状态 API恢复，不依赖浏览器本地状态。

## 测试

- Python 单元测试先覆盖重复姿态与失败像素门禁在写入前被拒绝，以及 JSON 输出契约。
- Node 测试覆盖自动编号、并发闭锁、白名单响应、本机访问限制与 runner 失败。
- 浏览器冒烟测试覆盖双画面、进度渲染、按钮互锁、成功/失败提示及零机械臂控制入口。
- 最后在当前 3100 只读/模拟服务上检查页面、API 和真实双相机采集失败/成功路径；机械臂控制保持关闭。
