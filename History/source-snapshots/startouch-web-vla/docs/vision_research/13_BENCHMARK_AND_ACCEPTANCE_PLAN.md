# Benchmark 与验收计划

## 数据集层级

### L0 合成单元数据

相机射线、SEUCM 有效域、刚体变换、z-buffer、遮挡、时间戳、状态机事件序列。纳入固定随机种子和属性测试。

### L1 录制回放

只读录制 Lumos RGB、D435 depth/RGB、相机元数据和机器人 pose。每条录制有 manifest、校验和、标定版本、场景标签。CI 使用小型脱敏 fixture，完整数据在 Ubuntu 本地。

### L2 静态物理标定

AprilGrid/平面/已测量对象，不动作或由用户手动拖动/摆放。评估内参、双相机注册和全链静态一致性。

### L3 Dry Run

在线相机但执行器物理隔离，生成候选/拒绝原因/计划预览，不发送动作。故障注入覆盖相机断连、stale、标定无效、目标换 ID。

### L4 人工分阶段实机

不属于自动实现。由用户现场逐步批准：预抓取安全高度 -> 接近但不闭合 -> 低速单物体抓取 -> 放置 -> 干扰/遮挡。每级通过后才进入下一级。

## 指标

| 子系统 | 指标 |
|---|---|
| Lumos 模型 | 独立集 reprojection median/P95/max，径向环带残差 |
| 深度注册 | 像素对齐 P50/P95、平面 mm 误差、mask 覆盖率、飞边率 |
| 检测/分割 | per-class box/mask AP、recall、空场景 FP、径向分桶 |
| 跟踪 | HOTA、IDF1、ID switch、fragmentation、遮挡重关联 |
| 对象三维 | base-frame jitter、绝对位置误差、covariance calibration |
| 抓取候选 | 点云纯度、candidate recall、碰撞拒绝、IK 可行率 |
| 状态机 | 非法推进次数、超时响应、重复事件幂等、审计完整性 |
| 性能 | capture-to-result P50/P95、FPS、掉帧、CPU/GPU/VRAM |

## 关键接受门限

- 单元/属性测试 100% 通过；坐标和状态机关键模块无跳过测试。
- 现有错误 RPY 实现的回归用例必须失败，正确实现误差 <1e-9（矩阵范数容差）。
- 合成深度注册在无量化时像素误差 <0.5 px，z-buffer 始终选最近表面。
- 回放时目标稳定后 base 位置 P95 jitter ≤8 mm；目标不可见/过期时抓取候选数必须为 0。
- detection/segmentation 目标类 recall ≥0.90；mask 路线的对象点云纯度 ≥0.95。
- tracker 遮挡测试重关联率 ≥90%，对象记忆误合并率 ≤1%；歧义时宁可拒绝。
- 所有 stale、低深度覆盖、标定 invalid、越界、无 IK、断连输入 100% 被 Dry Run 拒绝。
- 状态机 10,000 组随机事件序列中无法绕过批准；错误/超时后不再推进。
- 端到端 Dry Run P95 ≤300 ms，GPU 显存 <7.2GB，连续 30 分钟无增长性泄漏。

## 回归场景

1. 单瓶居中、边缘、部分遮挡。
2. 两个同类杯交叉/遮挡。
3. 罐与瓶类别混淆。
4. 透明杯、反光罐、黑色盒低深度。
5. 目标移出 Lumos 视场后返回。
6. 相机静止与机械臂运动（运动时必须拒绝候选）。
7. D435 无帧/Lumos 无帧/时间戳陈旧。
8. 错误外参、单位 ×1000、矩阵方向反转。
9. 重复、乱序、无关 `command_complete`。
