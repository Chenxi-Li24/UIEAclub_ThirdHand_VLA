|---|---|
| 现场条件 | 用户确认有人值守、能操作急停、工作区已清空 |
| PCAN | 重插后识别为 `0c72:000c`、`can0`；初始 DOWN |
| CAN 恢复 | 沿用仓库启动说明的 1,000,000 bps、restart-ms 100，启用 can0 |
| SDK 连接 | 2026-10-31 02:12:23（北京时间）发起，通过已有本机 Robot 服务 |
| 六关节状态 | 连续 24 条有效状态；序号递增，报告 moving=false；首末关节位置相同 |
| 测试指令 | 仅 connect、get_state、disconnect；运动/归零/夹爪指令 0 条 |
| 测试退出 | 收到 disconnect 确认；最终 connected=false、moving=false |
| CAN 计数 | 测试后 RX/TX 各 15,324 包，错误计数 0；RX dropped=38，保留该观察值，不能称零丢包 |

| 视频范围 | 仅回环网络；不录制、不另开相机采集进程、不发送 SDK 指令；临时传输进程已清理 |

详细证据位于本任务忽略目录 `evidence/C3-robot-connection.json` 与 `evidence/C3-camera-after-replug.json`，不含凭据。SDK 测试使用 Ubuntu 已有服务，未覆盖两个带未提交修改的工作目录，未重启 Robot 服务。

## 仍未通过或未测试

- 当前画面没有可靠的传感器采集时间戳；接收时间不能替代采集时间，只允许观看，远控画面时效检查保持不通过。
- PCAN 报告的序列号为 FFFFFFFF，不能作为唯一设备身份；公网真机控制需要人工绑定实际机械臂和执行实例。
- 未验证运动、真实停止时间、故障停止、网页/CLI/后台统一仲裁、控制权接管、遥测持续入库或公网 SDK 控制。
- 断开成功仅证明本次通信流程正常退出，不能替代真实停止能力验收。
- 后续运动测试仍需具体目标、速度、最大时长、停止判据和现场许可。本次没有批准任何运动轨迹。
