## 模块与协议

- `services/edge-agent/.../latest_state.py`：单个 SSE 读取线程更新一个槽；5Hz 上限发送，无补发队列，2 秒网络超时。连接事件只提供实际连接布尔值，不创造关节、夹爪或运动反馈。
- `remote-gateway.js`：事件增加源单调时钟；不改控制器、SDK 初始化或运动逻辑。
- `services/device-relay/src/latest-state.js`：当前 device/boot/executor/connection/certificate 绑定，签名、序号、时间和字段白名单；最多128设备。
- `/edge/v1/state`：现有 mTLS 加设备 Ed25519 签名；24,000字节上限。旧代际、重复/倒序、未来或超3秒请求拒绝。
- `/api/v1/devices/:id/state`：`telemetry.read`、设备启用检查、no-store；响应为 display-only，包含来源、序号、代际、新鲜度、采集/接收时间。
- `device-state.js`：可见页1Hz轮询，最多一个请求；失败2/4/8秒退避，后台暂停；250ms本地新鲜度更新。重复响应不能延长新鲜期。
- 缓存年龄采用来源年龄加传输时间、采集墙钟差的较大值；云端接收后使用单调时钟，浏览器独立累加。未来时间或不可靠时钟不显示新鲜。Linux 时钟需正常同步。
- `GET /api/v1/me/security`：仅返回本人模式、角色和是否已绑定 MFA，无认证材料。
- `workspace-navigation.js`、账户模块、`history-page.js`、教程适配和共享样式完成入口与布局整理。

无数据库迁移、授权 SQL、第三方依赖或模型资源变化。历史查询补充数据库已有速度、电流、扭矩、温度、夹爪列。
实时缓存必须与单实例设备中继共进程；重启后先显示未知，不能从历史库恢复“新鲜”状态。
源单调纳秒目前采用安全整数；超出 JavaScript 安全范围会拒绝上报并过期，不能改成假新鲜。长期连续运行需在后续协议版本改为十进制字符串。
