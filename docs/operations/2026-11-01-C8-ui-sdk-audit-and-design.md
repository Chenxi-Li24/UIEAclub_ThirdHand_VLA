## 3. 功能分类、入口位置与前后对照

新版一级导航建议：**总览 / 模型工作台 / 相机 / 数据 / 设备与诊断**，管理员按能力显示**标定 / 助手**。模型工作台保留原手动控制的内容，不丢弃TCP等接口；能力未就绪的管理员功能有说明。
固定辅助入口：导航顶部旁的展开/收起；导航底部“新手入门”和“账户头像”。退出进入账户菜单，桌面菜单和窄屏账户页均可访问。全局状态在顶部，页面操作在内容区。

经典保持**全屏模型视口+右侧控制抽屉**，不增加常驻左导航，不复制现代页卡外壳。顶栏按“品牌/当前模式/设备状态—模型、相机、数据、设备—账户/更多—抽屉开关”分区；语言/配色可从更多快捷进入账户偏好。右抽屉分组折叠：模型关节与夹爪、模型预设与点位、真实反馈；相机切换到同一个抽屉的相机内容。数据/账户/设备使用可关闭的工作面板，关闭返回同一模型视角和草稿。

| 现入口 | 新版位置 | 经典位置 | 理由 |
|---|---|---|---|
| 运行记录在退出下面 | 一级“数据” | 顶栏“数据” | 数据不是账户操作，观察员也常用 |
| 运行导出在长页面下方 | 数据页“导出任务”子区；筛选行“导出当前筛选” | 同一数据面板 | 明确导出范围、进度、下载结果 |

## 4. 账户结构与操作流程

```
账户（一级固定入口）
├─ 个人资料：身份/邮箱只读 → 编辑显示名、组织 → 保存/取消
├─ 安全与登录：当前模式、MFA状态、管理员申请/切换、退出
│  ├─ 未绑定MFA：密码验证 → 扫码与OTP确认 → 私下保存恢复码
│  └─ 已绑定且需升权：密码验证 → OTP/恢复码 → 管理员模式
├─ 界面偏好：新版/经典、各自配色、语言、背景、学习入口
└─ 成员与权限〔仅管理员模式〕
   ├─ 成员列表：搜索/分页、详情、CSV
   └─ 管理员申请：理由/状态、审批
```

- 普通观察员看自己的资料、偏好、安全/申请，不看成员、申请审批或账号审计。拥有admin角色但当前observe模式者也不显示管理目录；可在安全页升权。
- 管理员模式继续保留现有敏感操作的理由、密码、OTP/恢复码及expectedVersion；不借排版改动移除认证、最后管理员限制或审计。
- 个人资料加载成功后去掉“尚未接入”的说明；邮箱呈只读字段和解释，不伪装成可编辑。
- 安全页初始显示已绑定/未绑定及可操作入口。仅触发敏感动作才出现密码；验证后清理输入并只显示当前步骤，成功反馈返回安全摘要。MFA秘密、恢复码不进日志/截图/本地存储。
- 停用/撤权先打开成员详情中的危险操作区，确认对象、影响、理由及认证，再提交；成功更新该行并显示反馈。取消不发写请求。
- 桌面二级导航+内容区；<=650px改二级选择器/横向分类，表单单列。成员长表改摘要卡，详情承载邮箱/时间等低频字段；不是把所有按钮挤在右上角。
- 本轮不承诺新增会话管理、密码改名等后端尚无完整能力的入口；现有忘记密码流程保留。

## 6. 真实SDK状态同步设计（本阶段首要实施项）

### 当前链路与缺口

现有链路：Startouch SDK → Python bridge → Robot controller → edge采集/归一化 → SQLite outbox → 云端PostgreSQL → `/devices/:id/telemetry` → 管理员pre文本。
bridge默认轮询50ms（配置可改，不能当线上已验证频率）；controller把rad转换为deg供事件；edge再转rad入库。C3a实测历史入库P95约16秒，故不能直接靠更频繁查询历史库实现实时。

### 拟采用的双通道

```
已建立的只读 SDK 连接
  └─ 同一实际测量事件
      ├─ 完整归档 → 原outbox/批量上传 → PostgreSQL → 历史/导出（保留）
      └─ 最新快照 → Ubuntu主动mTLS状态上传 → 云端有界快照缓存
                                            └─ 鉴权只读GET → 浏览器共用状态store
                                                         ├─ 顶栏/总览
                                                         ├─ J1–J6/夹爪/设备详情
                                                         └─ 可选只读模型跟随
```

快照通道单独路由/队列，不将读取动作塞进运动命令队列，不等待归档积压；可复用现有443和设备身份机制，但新增路由/证书权限/服务配置须提交固定部署差异后再应用。不开放SDK端口到公网。云端多进程时快照一致性须由共享存储或独立状态服务保证，不能每实例各自缓存而轮流倒退。

初版拟最新值上报上限5Hz、浏览器可见时1Hz读取、仅一个在途请求；失败退避2/4/8秒，后台暂停，回前台立即读取。所有组件共享一次订阅，不各自轮询。历史全量采集频率保持原策略，快照丢中间帧不等于丢历史记录。
快照请求失败时本地时钟仍继续计龄；不因每次HTTP200、重复帧或页面刷新而重新变绿。建议新鲜阈值3秒，最终以实测预算审批；达不到就显示延迟/过期，不能只扩大阈值掩盖网络问题。

### 字段与单位契约

| 字段 | 来源/存储单位 | 网页 | 规则 |
|---|---|---|---|
| deviceId、bootId、executorEpoch、sequence | 设备身份/当前执行实例/序号 | 详情可查 | 当前代际内严格递增，拒绝重复/倒序；旧启动历史不能覆盖新快照 |
| sourceMode | 设备侧实供hardware | “真实机械臂” | dummy/simulation必须标测试，不得默认为hardware |
| jointPositionRad[6] | SDK实际关节角rad（事件deg只在边界转换一次） | J1–J6度，2位小数 | 六维、有限数；不能填入目标滑条值 |
| jointVelocityRadS/torqueNm/currentA/temperatureC | 实测可用字段 | deg/s、N·m、A、°C | SDK不提供则null+availability=false，显示“不提供” |
| gripper.positionRatio / widthM | gripper_position / gripper_width_m | 0–100%、mm | 分别校验；无校准时不从百分比推断毫米；不拿目标开度当反馈 |
| sdkConnected/moving/fault | 新鲜实际状态/SDK错误 | 已连接、运行状态、错误说明 | 未提供为unknown；缺失moving不能显示“已停止” |
| flangePositionM / orientation | SDK法兰参考 | mm与明确坐标系 | 不将法兰自动叫TCP；TCP需工具/标定版本和有效变换 |
| capturedAt、receivedAt、age、clockQuality | 源UTC/单调采样年龄、云端接收时间 | 采集/接收时间和“距今” | UTC保存、用户本地展示含时区；未来时间/时钟漂移不作新鲜证据 |
| fieldAvailability、qualityFlags | 采集质量 | 字段说明/异常提示 | 未知、读取错误、不支持分开；不传任意原始秘密/配置 |

### 状态机和身份边界

分别显示“网页↔业务API”“云端↔Ubuntu网关”“SDK连接”“测量数据”。

| 显示 | 必须有的证据 | 组件行为 |
|---|---|---|
| 未知/未读取 | 没有当前证据 | --，不使用仿真值补齐 |
| 连接中 | 管理员明确请求只读连接，设备已接收 | 显示进度/超时，不提前显示已连接 |
| 已连接·数据新鲜 | 当前epoch报告连接且合格样本age<=阈值 | 更新六轴/夹爪、显示时间与来源 |
| 已连接·等待首帧 | 当前连接证据存在，无有效样本 | --，超时转读取失败/过期 |
| 数据过期 | 样本年龄超阈值，连接未能确定断开 | 冻结最后实测值并标历史，取消模型跟随 |
| 已断开 | 当前设备明确sdkConnected=false | 清楚标断开，旧值仅作为最后记录 |
| 读取失败 | 有效会话但状态请求/解析/SDK读取失败 | 显示错误及重试，不把401以外网络错误当退出登录 |

管理员仅在设备页主动申请只读连接；复用已部署C3a只读适配器，实施前确认SDK连接初始化调用链没有enable/home/zero等副作用。观察员只能看已存在的反馈，不能创建SDK连接、申请控制权、调用语音或运动。设备列表权限与最新反馈读取权限沿用telemetry.read；敏感账户权限不扩大。
旧版连接指示/底栏全部读此store，不伪造旧WS“connected”来骗绿灯；UI状态灯不是授权门禁。

### 模型隔离与可选跟随

默认“编辑仿真”。真实反馈独立数值卡，模型滑条和个人点位保持原本草稿。
“跟随真机（只读）”需用户显式开启且有新鲜hardware数据；进入前保存当前仿真草稿，暂禁模型编辑/点位调用，持续标注只读跟随。退出后恢复原草稿。
数据过期/断线立即冻结并退出跟随；恢复数据不自动恢复跟随、不重放命令。历史回放单独标“历史”，不进入实时状态store。为缩小首版范围，可先上线真实数值同步，跟随在后续小阶段启用。

### 数据库与接口改动范围

现有robot_samples已含gripper/速度/扭矩等列，先补归一化和查询映射，避免无必要迁移；历史原始数据不回填推测值。
新增当前快照响应版本（建议GET `/api/v1/devices/:id/state`）承载当前连接、代际、字段可用性、新鲜度；原telemetry接口保留为历史兼容，不能悄悄改变其语义。
新接口/状态缓存均鉴权、no-store；允许显示字段使用白名单；freshness以服务端和源单调年龄推导，不相信浏览器墙钟。持久化连接/断线/读取错误事件供历史页追溯。

1. **冻结基线和映射**：重新核对login远端、其他任务改动、线上发布；记录当前路由/权限/截图/性能预算；只暂存本任务文件。确认本方案后才改业务源码。

5. **复用教程修正**：语义目标映射、角色文案、滚动/遮罩/退出/恢复进度；与队友正式provider保持边界。
6. **回归与候选**：完整矩阵，默认英文/浅色、新旧主题、长姓名、空/失败/加载/大量数据；账户安全、成员操作确认取消、CSV公式防护/鉴权、历史日期输入/日历、点位隔离、慢Three/慢profile/慢SDK、状态故障恢复。固定源码/资源清单、数据库变更和回退材料完成后才申请实际部署。

8. **复核交付**：逐问题标已修复/未修复，提供前后截图、实际断言、设备证据、性能对照；用户复核后再进入真机运动或正式生产发布阶段。
