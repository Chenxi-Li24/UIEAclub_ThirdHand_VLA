## 待批准的具体范围

在Ubuntu100.85.63.78，仅对wlp7s0临时执行 /usr/sbin/iw dev wlp7s0 set power_save off。

1. 变更前确认SDK断开、无活动租约和运动。
2. 先以sudo systemd-run创建独立15分钟恢复定时器，命令为 /usr/sbin/iw dev wlp7s0 set power_save on；确认定时器已排程，再关闭节电。
3. 复测同样的有限HTTPS响应（计数状态码），查看已有WSS的TCP计数及SDK租约续期。
4. 若链路满足期限，再执行此前已批准的显式SDK初始化与只读状态验收，允许既有使能和默认闭爪副作用，不发送后续运动。
5. 测试结束或失败后恢复power_save on并核对；独立定时器作为兜底。15分钟到时必恢复，不自动延长。

不改NetworkManager持久配置、不切换SSID、不重连Wi-Fi、不改路由/DNS/Tailscale、防火墙、端口或数据库，不重启设备服务。测试期间可能增加网卡功耗；关闭节电不等于修复网络，仍需按实测判断。
