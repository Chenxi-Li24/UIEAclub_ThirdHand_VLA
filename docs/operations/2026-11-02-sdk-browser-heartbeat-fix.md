同一个管理员账号选Observer登录时适用SDK窗口；Administrator模式仍采用原严格控制窗口，本包不声称解决管理员模式的长延迟控制。SDK生命周期与运动租约彻底拆分仍为后续工作。

SDK定时续约不是无限后台保活：每次都重新检查账户/会话/权限、原浏览器绑定及新鲜度、设备generation/readiness、数据库未过期租约；任何一步失败就撤销。浏览器3秒无新鲜证明后，最多一个100ms检查周期开始撤销；即使撤销包丢失，最后一次已发送租约仍受设备本地1秒上限约束。这是授权撤销边界，不是物理机械臂停止保证。

页面隐藏仍主动关闭通道；会话撤销和设备掉线立即清理，不自动重新申请或连接SDK。角色/模式/roleVersion不符不能复用旧连接。客户端只接受服务端协商的500ms或观察模式3000ms，重连默认回到500ms；迟到HTTP结果不能复活已关闭授权。观察员不能发送运动/接管/停止其他持有人，readOnly保持。

无数据库迁移、权限授予、新依赖、资源下载或新端口。沿用node services/cloud-api/src/main.js与既有业务/Robot/edge用户服务；设备快照切换需暂停代理再重启Robot后恢复代理，可能短暂重连相机。配置和回退以新固定部署审阅为准。
