- 手动输入关节（包括暂时空白/非法草稿）、滑条、夹爪、法兰位姿，或执行模型预置/个人点位/动作序列，会暂停整个姿态跟随；后台实测读数仍更新。重新勾选同步立即恢复最新有效反馈。断线重连不清除手动草稿；页面重新加载恢复默认跟随，不增加跨刷新草稿持久化。

- 数据过期、断线、读取失败、非hardware、SDK未连接或超模型范围均不驱动模型；保留最后姿态并提示等待/无法表示，不用零值/仿真状态冒充实测。
- 实时角度折叠按钮在现代工作台绑定点击；经典布局阻止冒泡，避免一次点击被两层处理。中英文增加跟随、手动暂停、等待以及通道中断原因。
- 无数据库/API/schema/依赖/权限/租约时限/Ubuntu配置变更。沿用已有本地cloud工作台启动流程；普通legacy `main.js`入口不改变。仅云端六件前端源码进入后续固定包。
