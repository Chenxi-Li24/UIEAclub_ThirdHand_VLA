# 网页抓取与 TCP 标定闭环

在 Xavier/web-grasp-tcp-integration 分支复用最新主线网页及已有实验抓取/TCP 模块，不整体合并分叉历史。不修改原始本地目录，不部署、不触发实机运动，不新增 CAN/SDK 控制所有者，不改阻尼。

## 接通范围

主页面选定目标，一键启动后经现有 9983 网页转发完成深度获取、手眼换算、路径检查、张开、预接近、刷新目标、接近、闭合、抬升。网页持续显示阶段、目标基坐标、路径分段、深度帧数、TCP 来源和结束/失败原因；完成表示控制链结束，不伪造实物抓取验证。

标定页面从主页面进入，支持拟合、独立验证、推导、保存、激活和回滚。识别当前主线 fixed_tcp_demo 能力但不授权该命令。服务没有示教接口时，只允许操作员确认已经静止并保持的姿态；不添加零阻尼实现，不将缺失接口伪装成成功。采样仍要求新鲜、健康、规范化且连续稳定的反馈。

## TCP 使用

每次新抓取从同一标定存储读取已激活候选，校验内容哈希、拟合和验证接受状态、坐标策略身份与刚性矩阵，并冻结整个会话使用的完整 T_flange_grasp_tcp。已激活但损坏/身份不一致必须拒绝启动。没有激活结果则明确使用既有近似 60 mm TCP 和 60 mm 水平经验退让；实测 TCP 默认不叠加这项经验退让，允许单独配置 calibratedForwardBackoffM。目标姿态保持当前夹取 TCP 姿态，再将完整刚性变换逆解到法兰及 SDK 工具坐标，不重复偏移。

标定切换、示教、采样等修改与抓取/深度运动互斥；软件停止始终可用。重连读取当前状态和配置，不依赖遗失的广播。

## 可迁移配置

新配置使用仓库相对路径和当前代码/SDK 文件哈希。手眼矩阵保持原值，只重绑一致的坐标策略身份并记录原文件哈希；保留物理验证 pending/false。统一运行配置启用这些接口并提供视觉规范化策略及数值手眼投影开关。旧证据原封保留，不宣称重新完成标定。

## 验证

离线测试真实几何、存储、会话和 HTTP/WS 入口，使用本机模拟机器人/视觉反馈，不连接真实设备。覆盖缺失/损坏 TCP、不同旋转及非轴向平移、会话冻结、缺失示教、互斥、页面恢复和失败展示。保留主线 Dummy/语音/控制测试；最终独立只读审查。远端部署和实物效果不属于本次完成声明。
