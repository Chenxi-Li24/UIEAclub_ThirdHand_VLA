# 鱼眼视觉与相机模型研究

## 模型选择

Lumos 厂商参数明确标注 SEUCM。工程上先按 EUCM/SEUCM 实现原生投影与反投影，并用 Double Sphere 与 Kalibr EUCM 作为交叉验证。不要先把 220° 图像整体拉直成针孔图像：全图重采样会降低边缘有效分辨率、裁掉视野并引入额外插值误差。

核心候选：

| 模型 | 优点 | 风险/用途 |
|---|---|---|
| EUCM/SEUCM | 与厂商参数一致；投影/反投影闭式；参数少 | 需严格实现有效域；`Z>0` 不是 220° 相机的充分有效域 |
| Double Sphere | 大视场拟合好、计算快、闭式反投影；Kalibr 支持 | 与厂商参数不直接兼容，需重新标定作对照 |
| Kannala-Brandt/equidistant | 工具成熟 | 未必能解释厂商 SEUCM 参数；极端边缘需实测 |
| OpenCV pinhole/radtan | 通用工具多 | 对 220° 全视场不适用，拒绝作为生产模型 |
| OpenCV omnidir/Mei | 可处理大视场 | 参数定义与 SEUCM 不同，不可直接套用 |

## 数学约定

EUCM 投影（相机点 `p=(x,y,z)`）：

```text
d = sqrt(beta*(x*x + y*y) + z*z)
den = alpha*d + (1-alpha)*z
u = fx*x/den + cx
v = fy*y/den + cy
```

实现必须先检查模型论文给出的有效投影域与 `den > epsilon`，而不是简单要求 `z > 0`。反投影输出单位射线并明确其范数；深度融合时 D435 点已经是三维点，不把 Lumos 射线与 D435 Z 直接相乘。

## 标定与验证

1. 先验证厂商参数：用覆盖中心、边缘、四角和超 180° 区域的 AprilGrid/ChArUco 图像，计算独立保留集重投影误差。
2. 用 Kalibr 的 EUCM 与 Double Sphere 分别标定。Kalibr 支持 `eucm [alpha,beta,fu,fv,pu,pv]` 和 `ds [xi,alpha,fu,fv,pu,pv]`，且推荐 AprilGrid，因为可部分可见且不易姿态翻转。
3. 分区域报告 RMS、median、P95、max，而不是只给一个全局 RMS；同时画残差向量场，检查边缘系统偏差。
4. 保存原始图像、角点、配置、工具版本、随机种子、拟合/验证划分和校验和。

建议门限（需以机械臂重复精度和工作距离再校准）：验证集 median ≤1.0 px、P95 ≤2.5 px、边缘 P95 ≤4 px，且无明显方向性残差。现有 107.95 px 结果直接隔离。

## 对检测模型的影响

COCO 模型主要由透视图训练，鱼眼边缘对象会发生尺度、形状和方向域偏移。建议：

- Phase 1 原生鱼眼全图检测，并增加径向位置/尺度/旋转增强；保留全视场。
- 可选生成多个重叠虚拟针孔视图供现成模型推理，再把 mask/box 反投影合并；这是增强路径，不作为几何主坐标系。
- 数据集必须按径向环带统计 AP/召回率，不能只看全图 mAP。
- 2026 年鱼眼机器人研究指出广视场提升定位但依赖场景复杂度，跨相机迁移常因尺度过拟合失败；因此需要真实 Lumos 数据与随机尺度增强。

## 当前 `seucm_model.py` 审查

- 投影强制 `Z>0`，会错误排除可能属于超 180° 有效域的点。
- `project_with_depth()` 返回欧氏范数，但字段没有声明，容易与光轴 Z 混用。
- `get_fov()` 用角点 atan2 推断视场，在跨过 180° 时可能发生角度环绕。
- 没有投影/反投影互逆、有效域边界、数值稳定性和 Kalibr 对照测试。

实现前必须先补这些纯离线测试。
