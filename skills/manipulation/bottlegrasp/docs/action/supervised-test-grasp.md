# 人工确认测试抓取（当前为只读预览）

控制页的“测试抓取 · 每步确认”与原有视觉夹取按钮完全分离。输入稳定目标 ID（1–5）并点击“读取目标”，可查看相机、目标表面和 GRIP 点坐标（米转毫米），以及阻断原因。只读 CLI：

```sh
node scripts/action/supervised_test_grasp.js preview --target-id 1
node scripts/action/supervised_test_grasp.js status
```

当前部署配置中的 `execution_enabled`、`grasp.offset_validated` 和手眼物理验证仍为关闭/待验证。新的监督路径也没有经过实测的 GRIP→法兰变换、动作证据 v3、预抓/转运路径验证，因此生产端故意不注入执行计划构造器；预览始终返回 `supervised_plan_unavailable`，不能开始运动。**不要仅修改布尔开关来解锁。**

将来解锁前，必须独立测量并验证夹爪中心相对法兰的刚体变换（20 mm 目前仅是候选值）、完成手眼 3D 误差实测、验证预抓与释放后路径、更新版本绑定的动作证据，且逐项确认现场操作员与实体急停可用。相机完全遮挡的 10 mm 说明不是安全距离。软件停止不是安全额定急停；如果机械臂有危险，请使用实体急停。每条运动指令必须由操作员单独确认，失联或超时不可自动续行。

此功能的离线测试不得连接 CAN、移动机械臂或夹爪。上线前须在受控现场重新审查配置、路径、日志和状态关联；本文不构成物理抓取授权。
