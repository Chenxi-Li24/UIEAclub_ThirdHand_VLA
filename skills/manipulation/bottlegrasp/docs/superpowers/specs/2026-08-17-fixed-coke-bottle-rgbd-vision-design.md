# 固定实验可口可乐瓶 RGB-D 视觉系统设计

## 1. 目标

视觉模块的最终用途不是单纯显示检测框，而是为机械臂完成“识别指定瓶子、夹取、搬运、放置”提供可靠的目标位姿。

第一版系统只面向一款固定规格的实验用可口可乐塑料瓶。在单瓶直立、桌面场景中，系统需要：

1. 从百事瓶、矿泉水瓶、普通瓶和罐子等干扰物中识别指定实验瓶；
2. 输出瓶身实例掩膜，而不是只输出二维矩形框；
3. 使用 XVisio 注册深度恢复瓶身三维点云；
4. 计算相机坐标系下的瓶身中心、瓶身轴线和建议侧向抓取位姿；
5. 通过多帧一致性检查决定结果是否可用于抓取；
6. 在手眼标定接入后，将相机坐标转换为机械臂基座坐标；
7. 任何关键证据不足时拒绝输出可执行抓取结果。

## 2. 范围边界

### 2.1 第一版包含

- XVisio 末端 RGB-D 鱼眼相机连续取流；
- 固定实验可口可乐瓶的身份识别与瓶型校验；
- RGB 实例掩膜与注册深度融合；
- 相机坐标系三维抓取位姿；
- 时间戳、置信度、质量指标和明确失败原因；
- 离线回放、静态实测和后续手眼接口；
- 只读参考其他目录，并将必要代码复制后在 `VA` 内独立改造。

### 2.2 第一版不包含

- 泛化识别所有容量、包装和版本的可口可乐产品；
- 把可口可乐罐当作目标；
- 依赖旧相机内参、旧手眼矩阵、像素比例或平面单应性；
- 实现或修改组员的语音识别、意图理解和任务编排；
- 求解组员负责的手眼标定，或在当前阶段生成基座坐标；
- 在视觉进程中直接控制机械臂；
- 动态目标抓取、严重遮挡抓取或任意堆叠场景；
- 视觉决定固定放置点。放置点由运动控制层配置。

## 4. 方案选择

### 4.1 推荐方案：预训练模型与固定目标校验的混合方案

使用现有 Grounding DINO 生成语义候选，使用 SAM2 生成瓶身实例掩膜，再通过固定实验瓶参考特征、竞争类别证据和瓶型几何进行二次校验，最后与注册深度融合得到三维抓取位姿。

优点：最大化复用现有成果，不需要第一天就重新训练大型模型；固定目标校验可以显著降低把百事瓶或可乐罐当作目标的风险；后续可平滑替换为专用分割模型。

### 4.2 备选方案：训练专用实例分割模型

采集并标注固定实验瓶、百事瓶、矿泉水瓶和罐子的图像，训练 RTMDet/YOLO 实例分割模型。该方案适合作为数据积累后的第二阶段，推理速度和稳定性更高，但首版需要额外采集、标注和训练工作。

### 4.3 不采用的主方案：颜色或模板匹配

传统颜色、边缘和模板方法可作为调试证据，但不作为抓取授权依据。它们容易受到鱼眼畸变、反光、曝光、旋转、部分遮挡和包装磨损影响。

## 5. 系统架构

### 5.1 相机采集层

职责：

- 校验相机序列号，防止误用旧相机标定；
- 持续获取完整 RGB 帧和 ToF 深度；
- 将深度注册到正式 RGB 输出坐标系；
- 为 RGB、深度和机械臂位姿保存可比较的单调时间戳；
- 输出相机模型、深度单位和有效性掩膜；
- 相机断开、帧超时、标定缺失或序列号不匹配时立即失败。

标准帧对象至少包含：

- `rgb`：完整彩色图；
- `depth_m`：与 RGB 像素对齐的米制深度；
- `valid_depth_mask`；
- `camera_model`；
- `camera_serial`；
- `frame_id`；
- `timestamp_monotonic_ns`。

### 5.2 目标识别与实例分割层

处理步骤：

1. Grounding DINO 使用可口可乐塑料瓶及竞争类别提示词生成候选；
2. SAM2 为每个候选生成实例掩膜；
3. 固定实验瓶参考特征库计算外观相似度；
4. 百事、普通瓶、矿泉水和罐子证据形成竞争分数；
5. 使用掩膜长宽比、轮廓、瓶颈结构和深度高度约束排除罐子；
6. 只保留身份、瓶型和竞争间隔同时通过的候选。

固定实验瓶参考特征库只需要覆盖实际工作条件下的正面、侧面、轻微旋转和常见光照。它不是通用产品数据集。

### 5.3 深度与三维几何层

处理步骤：

1. 腐蚀实例掩膜，避免轮廓处 RGB/深度配准误差；
2. 丢弃无效深度、飞点和超出工作距离的点；
3. 用稳健统计剔除背景与桌面点；
4. 将剩余像素通过当前相机模型反投影为三维点云；
5. 通过 PCA/稳健直线拟合估计瓶身轴线；
6. 在瓶身中部安全带内计算侧向抓取中心，避开瓶盖、瓶底和标签边缘；
7. 根据可见表面和瓶身轴线给出建议接近方向；
8. 计算深度点数、覆盖率、离散程度和抓取点不确定度。

抓取点不能直接使用二维检测框中心。二维中心只用于显示和候选关联。

### 5.4 多帧稳定与抓取授权层

使用最近 5 帧建立同一目标轨迹。至少 4 帧同时满足以下条件才授权输出：

- 固定瓶身份通过；
- 实例掩膜 IoU 和目标中心运动满足阈值；
- 三维抓取点离散程度满足阈值；
- 深度覆盖和有效点数满足阈值；
- 帧与机械臂位姿时间差满足阈值；
- 目标在允许工作区内。

授权结果必须有有效期。机械臂到达预抓取观察位后，应重新观察并生成新的抓取位姿，不能沿用远距离旧结果。

### 5.5 坐标变换与运动控制边界

视觉首阶段输出相机坐标系结果：

`T_camera_object(timestamp)`

手眼标定完成后，由集成层结合对应时刻机械臂末端位姿计算：

`T_base_object = T_base_ee(timestamp) × T_ee_camera × T_camera_object`

视觉模块不发送关节或末端运动命令。运动控制层负责：观察位、预抓取位、最终抓取、夹爪闭合、抬升、搬运和固定目标点放置。

当前阶段只保证输出稳定、带时间戳的 `T_camera_object` 及其质量指标。未来组员模块完成后，语音侧负责触发任务，手眼侧提供 `T_ee_camera`，集成层再完成坐标变换和抓放；这些未来接口不能成为当前视觉开发和测试的前置依赖。

## 6. 输出契约

成功输出至少包含：

```json
{
  "status": "ready",
  "target_id": "fixed_coke_bottle",
  "camera_serial": "250801DR48FP25002738",
  "frame_id": 123,
  "timestamp_monotonic_ns": 0,
  "bbox_xyxy": [0, 0, 0, 0],
  "mask_ref": "artifact:mask.png",
  "grasp_point_camera_m": [0.0, 0.0, 0.0],
  "bottle_axis_camera": [0.0, 0.0, 1.0],
  "approach_vector_camera": [0.0, 0.0, -1.0],
  "identity_confidence": 0.0,
  "depth_valid_ratio": 0.0,
  "position_std_m": [0.0, 0.0, 0.0],
  "stable_hits": 4,
  "window_size": 5
}
```

失败输出必须为 `status: uncertain` 或 `status: unavailable`，并提供明确原因，例如：

- `camera_unavailable`；
- `camera_serial_mismatch`；
- `rgb_depth_not_aligned`；
- `target_not_found`；
- `identity_conflict`；
- `container_type_not_bottle`；
- `depth_insufficient`；
- `pose_unstable`；
- `timestamp_stale`；
- `outside_workspace`。

失败结果不得携带可被误认为已授权的抓取位姿。

### 阶段 C：三维抓取位姿

### 阶段 D：静态验收

- 在不同桌面位置、朝向和常见光照下测试；
- 验证目标瓶不漏检、负样本不误授权；
- 验证深度覆盖、三维重复性和输出时效。

## 9. 验收标准

在进入实际夹取前，至少满足：

1. 相机连续运行 30 分钟无异常退出，帧编号和时间戳单调；
2. RGB 与注册深度在中央工作区对齐，无系统性像素偏移；
3. 固定实验瓶评测召回率不低于 95%；
4. 约定的百事瓶、矿泉水瓶、普通瓶和罐子评测集中不出现抓取授权误报；
5. 静态目标相机坐标三维抓取点重复性达到 5 mm 量级；
6. 深度不足、身份冲突、目标越界和时间戳过旧时全部拒绝授权；
7. 视觉进程始终不直接发送机械臂运动命令。

未来与手眼标定拼接后，再单独验收基座坐标抓取点 P95 误差不超过 10 mm；该指标不阻塞当前视觉模块的独立开发和相机坐标验收。

若某项指标受硬件噪声限制无法达到，应保留原始数据和误差报告，并在机械臂实夹前重新确定安全阈值，不能通过放宽失败条件掩盖问题。

## 10. 风险与控制

- **鱼眼畸变与深度视场较窄**：只在 RGB/深度共同有效工作区内授权抓取；
- **透明或反光塑料导致深度孔洞**：使用掩膜腐蚀、多帧融合和稳健统计，不用单像素深度；
- **可口可乐罐误识别为瓶**：身份证据与瓶型几何必须同时通过；
- **末端运动造成帧和位姿错配**：使用单调时间戳关联，并限制最大时间差；
- **旧标定被误用**：相机序列号、内参版本和手眼标定版本共同校验；
- **模型置信度漂移**：保留离线回放评测集，阈值变更必须重新跑正负样本；
- **视觉误报造成机械风险**：默认失败关闭，实际运动由独立控制层二次检查工作区和速度限制。

## 11. 设计结论

第一版采用“完整 XVisio RGB-D 连续流 + Grounding DINO/SAM2 + 固定实验瓶二次校验 + 掩膜深度三维几何 + 5 帧稳定授权”的架构。视觉模块的交付物是可靠、可追溯、带质量指标的抓取位姿，而不是检测框；机械臂控制和固定放置点属于后续集成层。
